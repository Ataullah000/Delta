# Ataullah Al Mahmud Digital Universe

A cinematic static portfolio built with HTML, CSS and vanilla JavaScript, with a Three.js 3D hero, film-grade ambience, parallax and smooth motion.

## Folder Structure (flat, easy for phone)

```
ataullah-portfolio/
├── index.html
├── about.html
├── vision.html
├── projects.html
├── skills.html
├── journey.html
├── certificates.html
├── contact.html
├── style.css        (design + premium visual layer)
├── main.js          (content, language, interactions)
├── universe.js      (3D scene + ambience, loaded by main.js)
├── favicon.svg
├── profile-placeholder.svg
├── robots.txt
├── sitemap.xml
└── README.md
```

## Before publishing

Edit only the CONFIG object at the top of `main.js` if needed (email, social links).

## Local preview

Open `index.html` in a browser. No build step needed. Internet is needed for fonts and the Three.js 3D scene (loaded from cdnjs); without it the site still works, just without the 3D orb.

## GitHub Pages / Netlify

Upload all files keeping them in one folder. Deploy from root.
